HOW TO READ THIS TIMELINE

Linux is the kernel: the core that manages hardware, memory, processes, and other low-level resources. A Linux distribution combines the kernel with software, tools, package management, and often a desktop environment to make a usable operating system.

UNIX is the short background chapter here—not the main timeline. Linux was created independently as a UNIX-like kernel; it is not simply a later version of the original UNIX source code.

THE BIG PICTURE

UNIX → GNU tools + Linux kernel → distributions → user environments

That is a useful simplified map, not a universal recipe. Some distributions use other kernels, some systems omit a graphical desktop, and Linux can run in everything from tiny embedded devices to supercomputers.

This is a curated timeline, not a complete list of every distribution or kernel release. Linux history is collaborative and many developments overlap.
