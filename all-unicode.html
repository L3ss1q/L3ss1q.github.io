ALL UNICODE CODE POINTS

Every code-point value from U+000000 through U+10FFFF, including invisible, unassigned, reserved, and noncharacter values. Rows are generated only when you request a range, so the page doesn't try to create over a million DOM rows at once.

Unicode has 1,114,112 code-point values. Some are not assigned characters; some cannot be represented as Unicode scalar values; and browsers may not render every value as a visible glyph. The code point and numeric reference remain listed regardless.

Ready. Start with U+0000–U+04FF.
