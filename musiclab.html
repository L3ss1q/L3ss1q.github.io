INSTRUMENT COMPARISON LAB

One melody. Different timbres. Offline audio experiments.

01 / SOUND ENGINE

This lab uses the browser's built-in Web Audio synthesizer. It works offline, but these are synthesized waveforms—not recordings of real instruments.

02 / TIMBRE PRESETS

These are playful approximations, not faithful flute, string, or brass samples.

03 / TRACK A/B TEST

Choose a preset for each track, then compare the same phrase.

04 / NOTE EXPLORER

Tap a piano key to hear it. Use this to compare how the same note sounds in different registers and waveforms.

05 / EXPERIMENT NOTES

Scientific method: change one variable at a time. Keep the melody and tempo the same while comparing timbre; then change the register or note length separately.
