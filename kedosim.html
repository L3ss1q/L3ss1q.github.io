KEDO Terminal Simulator

A safe, browser-based pretend terminal inspired by KEDO DOS. Commands affect only this simulated filesystem.

KEDO DOS · simulator · local sandbox
KEDO>

Try these commands

  • help — list commands
  • ls — list files and folders
  • cd docs — enter a directory
  • cat readme.txt — read a file
  • echo hello world — print text
  • write notes.txt hello there — create or replace a file
  • mkdir projects — create a folder
  • touch todo.txt — create an empty file
  • whoami and ver — inspect the simulated system

Simulator notes

This is an educational simulation, not a real operating system. It cannot access your device's files, run programs, change accounts, or execute shell commands.

The filesystem starts with sample files. Changes stay in this page while it is open; use export to download a JSON save, or import to load one.

Tip: use help for the full command list. Commands are case-insensitive; file names are stored as typed.
