How it works
The grid has 16 steps per bar. Each column is one sixteenth-note step; each colored cell is a pitch. The drum row is a simple click sound. Use Save song to export a JSON project you can reopen, or Export MIDI to create a standard .mid file. The app uses your browser's built-in audio and works offline once this HTML file is saved.
