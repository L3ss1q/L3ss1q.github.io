05 / Tiny glossary

Bit

One binary digit: 0 or 1.

Byte

Usually 8 bits; 256 possible patterns.

Hexadecimal

Base 16, using 0–9 and A–F. One hex digit represents four bits.

Example: decimal 65 = hexadecimal 41 = binary 01000001 = ASCII A.
