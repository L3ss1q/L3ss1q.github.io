4. Control Flow

if / else

if (score >= 90) {
    puts("A");
} else if (score >= 80) {
    puts("B");
} else {
    puts("Keep practicing");
}

switch

switch (choice) {
case 1:
    puts("One");
    break;
case 2:
    puts("Two");
    break;
default:
    puts("Other");
    break;
}

Loops

for (int i = 0; i < 10; ++i)
    printf("%d\n", i);

int i = 0;
while (i < 10) {
    ++i;
}

do {
    /* runs at least once */
} while (condition);

break / continue

for (;;) {
    if (done) break;
    if (skip) continue;
}

void

C passes arguments by value. To modify an object in a function, pass its address.

void set_value(int *p) {
    *p = 42;
}

int x = 0;
set_value(&x);

6. Arrays

int numbers[5] = {10, 20, 30, 40, 50};

printf("%d\n", numbers[0]);

Array indexing begins at zero. Access outside an array's bounds is undefined behavior.

    {4, 5, 6}

Array length

7. Pointers

A pointer stores the address of an object or function.

int x = 10;
int *p = &x;

printf("%d\n", *p);
*p = 20;

NULL

int *p = NULL;

if (p != NULL)
    printf("%d\n", *p);

Pointer arithmetic

int values[3] = {1, 2, 3};
int *p = values;

printf("%d\n", *(p + 1));

Pointer to pointer

int x = 5;
int *p = &x;
int **pp = &p;

const pointers

const int *p;        // pointer to const int
int *const p2 = &x;  // const pointer to int
const int *const p3 = &x;

9. Structs, Unions, and Enums

struct Person {
    char name[32];
    int age;
};

struct Person p = {"Lucy", 13};
printf("%s\n", p.name);

Struct pointers

struct Person *ptr = &p;
printf("%d\n", ptr->age);

Unions

union Value {
    int i;
    float f;
    char c;
};

union Value v;
v.i = 42;

Union members share storage, so reading a member other than the one whose value is intended requires care and depends on the language rules and implementation.

10. Dynamic Memory

#include <stdlib.h>

int *p = malloc(10 * sizeof *p);

if (p != NULL) {
    p[0] = 123;
    free(p);
}

calloc

int *p = calloc(10, sizeof *p);

realloc

int *tmp = realloc(p, 20 * sizeof *p);

if (tmp != NULL)
    p = tmp;
Memory rule: Successful dynamic allocations should eventually be released with free, unless ownership is deliberately transferred.

12. File I/O

#include <stdio.h>

FILE *file = fopen("data.txt", "r");

if (file != NULL) {
    char buffer[128];

    while (fgets(buffer, sizeof buffer, file))
        fputs(buffer, stdout);

    fclose(file);
}
FunctionPurpose
fopenOpens a file.
fcloseCloses a file.
freadReads binary data.
fwriteWrites binary data.
fgetsReads a line or string.
fputsWrites a string.
fprintfFormatted output to a stream.
fscanfFormatted input from a stream.
fseekMoves the stream position.
ftellReports the stream position.

Common modes: "r" read, "w" write/truncate, "a" append, and "+" for update. Add "b" for binary mode where applicable.

15. C Standards

  • C89/C90: early standardized C.
  • C99: added features such as // comments, declarations in for loops, and <stdbool.h>.
  • C11: added features including _Static_assert, atomics, and threads support.
  • C17: maintenance revision of C11.
  • C23: the current ISO C standard with additional language and library features.

16. Important Rules

  • Arrays are zero-indexed.
  • C strings end with '\0'.
  • &x gets an address; *p dereferences a pointer.
  • sizeof reports a size in bytes.
  • C function arguments are passed by value.
  • Dynamic memory from malloc, calloc, or realloc is released with free.
  • Accessing an object outside its valid bounds is undefined behavior.
  • Using an object outside its lifetime is invalid.
  • Do not return a pointer to a local automatic object whose lifetime has ended.
  • Compiler warnings are extremely useful for finding mistakes early.
